## Важные ограничения

- Собственный опрос авторов и покупателей **не проводился**. В документе приведены внешние опросы РУССОФТ и ОПОРЫ и дизайн будущего исследования.
- Не рассчитаны TAM/SAM/SOM, не существует утверждённого бюджета или подтверждённого оператора.
- Упомянутые министерства, Сбер, RuStore и другие организации не выступают заявленными партнёрами.
- Показатели маркетплейсов — их собственные публичные заявления. Предложенная калькуляционная модель не является прогнозом.
- Для официального решения нужны отдельные правовой анализ, рынок, конкурсная процедура, проверка финансовой модели.
