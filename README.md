## Ограничения достоверности

- Собственный опрос авторов и покупателей **не проводился**. В документе приведены внешние исследования РУССОФТ и ОПОРЫ и план будущего исследования.
- Не рассчитаны TAM/SAM/SOM, не утверждены бюджет и оператор.
- Упомянутые министерства, Сбер, RuStore и другие организации не заявлены партнёрами.
- Показатели маркетплейсов являются их собственными публичными заявлениями. Калькулятор — иллюстративная модель, а не прогноз.
- Для официального внесения необходимы повторная проверка источников и отдельная юридическая экспертиза.
